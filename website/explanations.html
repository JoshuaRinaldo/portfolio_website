How It Works

This demo uses SHAP values to quantify each word's contribution to the model's prediction. The models are deployed as serverless endpoints on AWS SageMaker, with custom Docker containers that generate explanations in real-time.

Technical Details

  • Models: Fine-tuned transformer models (RoBERTa, DistilBERT) for text classification
  • Explainability: SHAP (SHapley Additive exPlanations) for model interpretability
  • Infrastructure: AWS SageMaker serverless endpoints with custom Docker containers
  • Frontend: Static HTML/CSS/JavaScript served via CloudFront
